# autonomous-proc
Architecting autonomous procurement ecosystems through sourcing, suppliers, spend, intelligence, AI, and connected networks.

## Procurement Gameboard Learning Model

The **Autonomous Procurement Gameboard Model** turns procurement learning into applied missions with tangible artifacts and evidence of capability. It adapts the six-part gameboard pattern to procurement: **Player Identity → Winning Promise → Level Ladder → Mission Design → Reward Engine → Growth Loop**.

Read the [Autonomous Procurement Gameboard Model](gameboard_model_autonomous_procurement.md) for the full blueprint, all eight learning formats, sourcing and supplier examples, 20-lab mapping, assessment guidance, and pilot plan.

### Eight Learning Formats

| Format | Primary purpose | Example procurement use |
|---|---|---|
| Webinar | Awareness and orientation | From Business Need to Better Buying |
| MasterClass | Expert judgement and complex sourcing decisions | Strategic Sourcing Decision Lab |
| Workshop | Practise one focused skill | Supplier Scorecard Studio |
| Bootcamp | Build connected procurement capability | Source-to-Contract Architect Bootcamp |
| Hackathon | Solve a challenge and demonstrate execution | Procurement Value Challenge |
| 21-day Challenge | Build daily practice and procurement judgement | Daily Procurement Judgement |
| Sprint | Finish one defined deliverable | Five-Day Supplier Risk Sprint |
| SuperClass | Enterprise strategy and advanced judgement | Autonomous Procurement Strategy SuperClass |

Choose the format according to learner intent, depth, and expected output. A format is not a curriculum by itself; combine formats deliberately and assess each one proportionately.
